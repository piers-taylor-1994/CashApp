# Till Practice

A small, offline-capable web app (a PWA) that helps a shop or till worker practise handling cash:

- **Identify coins and notes.** A coin or note is shown; tap its value. Look-alikes (10p, 20p, 50p; £1 and £2) are used as distractors. "Coins only" is an option.
- **Count-up change.** Given a price and the amount handed over, build the change in a tray or choose the total. Then reveal the count-up sequence step by step.
- **Till scenarios.** "Customer buys X, hands over Y. What do you give back?" with a hint button and the same tray.
- **Pick the money.** Build a target amount with the fewest pieces.
- **Progress.** Correct and attempted counts per mode, saved on the device, with a reset button.

It is plain HTML, CSS and vanilla JavaScript. There are no frameworks, no build step, no npm dependencies and no CDN links. After the first load it works offline.

## Run locally

From this folder:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Run the tests

```sh
node --test tests/
```

The tests use only Node's built-in `node:test` runner. The pure money logic lives in `js/money.js` and has no DOM access.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository (for example `money-practice`).
2. Push this folder's contents to the `main` branch.
3. In the repository, go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save.
5. After a minute or two the app is at `https://<your-user>.github.io/money-practice/`.

All paths are relative, so the app works from a subpath. The empty `.nojekyll` file tells GitHub Pages not to run Jekyll.

When you change the app, bump `CACHE_VERSION` in `sw.js` (for example to `till-practice-v2`). Otherwise phones that already installed it will keep showing the cached version.

## Install on a phone

**iPhone (Safari):** open the site in Safari, tap the Share button, then **Add to Home Screen**.

**Android (Chrome):** open the site in Chrome, tap the menu (three dots), then **Install app** or **Add to Home screen**.

## Icons

The PNG icons in `icons/` are generated by a dependency-free script. To regenerate them:

```sh
node tools/make-icons.mjs
```

## Accuracy notes

- **The artwork is stylised.** Coin and note pictures are simplified teaching aids. Colours are chosen so pieces can be told apart. They are **not to scale** and are **not** copies of any official Bank of England or Royal Mint design. Do not use the pictures as a reference for real notes.
- **Coin sizes** in the feedback text use the commonly published diameters, with the 20p and 50p as seven-sided and the £1 as twelve-sided.
- **Scottish and Northern Irish notes are not included.** Only the Bank of England notes are covered.
- **Check the facts yourself.** Please double-check the current legal-tender status and designs against the Bank of England (bankofengland.co.uk) and Royal Mint (royalmint.com) websites before relying on this for training.
